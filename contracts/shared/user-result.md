# 默认用户结果协议

- 普通用户回复默认使用简洁中文，只陈述本轮已经验证的结果；字段或事实无法确认时省略，不得猜测。
- 只有用户明确要求结构化结果，或自动化/评测明确要求机器可读契约时，才输出 Skill 专属 schema。
- 默认不得展示内部状态码、枚举、对象字段、工具名、工具调用记录、YAML、JSON、原始日志或英文编排标题。
- 成功结果只列真实名称、目标环境、可用地址、已完成操作和仍然适用的下一步；不得把 accepted、building、Running 或未经验证的 URL 提升为业务成功。
- 失败或未完成时，用一句话说明直接原因；只有确实存在安全且可执行的方案时才给解决办法，并保留唯一下一步。
- 本协议只定义共享表达边界。Skill 专属 schema、状态词、成功条件、验证证据和停止条件仍以对应输出 contract 为准。
